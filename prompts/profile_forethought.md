### The Multi-Agent Architecture

1. **Solve Agent (Autonomous Tier-1 Resolution)**:
   - Omnichannel autonomous AI resolving up to 98% of routine support inquiries across Web Chat, Email, Voice, SMS, WhatsApp, and Slack.
   - **Autoflows**: Build and adapt complex resolution logic in natural language without brittle decision trees.
   - **Custom Actions**: Executes end-to-end transactional workflows via real-time API calls (e.g. process refunds, update shipping addresses, cancel subscriptions, verify identity).
   - **Browser Agent**: Navigates legacy internal back-office applications without APIs to execute workflows on behalf of agents.
2. **Triage Agent (Predictive Tagging & Routing)**:
   - Evaluates incoming tickets in sub-seconds to predict intent, sentiment, language, and custom fields with 90%+ accuracy.
   - Automatically routes tickets to the right team or tier, eliminating manual triaging queues.
3. **Assist Agent (In-Helpdesk Copilot)**:
   - Embedded directly inside the agent workspace (Zendesk, Salesforce, etc.).
   - Surrounds the human agent with real-time contextual recommendations, instant CRM lookup data, and 1-click personalized response drafts.
4. **Discover Agent (Knowledge & Topic Intelligence)**:
   - Continuously analyzes customer conversation trends to pinpoint gaps in knowledge bases and automatically drafts updated help articles.
5. **QA Agent (Automated 100% Quality Assurance)**:
   - Automatically inspects, grades, and tags 100% of human and AI customer conversations for compliance, empathy, and SLA standards.
